RAPPEL : FORMAT DE NOMMAGE
---------------------------
Bâtiments : building-<key>.webp
Vaisseaux : ship-<key>.webp

Remplacer les underscores _ par des tirets -
Exemple : heavy_hunter → ship-heavy-hunter.webp


PROCESSUS RAPIDE
-----------------
1. Créer vos images (PNG/JPG) avec ces noms
2. Les placer dans frontend/public/images/buildings/ ou ships/
3. Lancer ./optimize_images.sh
4. Vérifier que les .webp sont créés
5. Tester dans le jeu !
